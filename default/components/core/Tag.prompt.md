A square, hairline, monospaced chip for metadata — indices, source labels, status, tags. The texture element of the language.

```jsx
<Tag>SOURCE 03 / 12</Tag>
<Tag tone="hot" dot>LIVE</Tag>
<Tag tone="solid">φ-ALIGNED</Tag>
```

Tones: `default` (grey hairline), `hot` (blue hairline), `solid` (blue fill, black text). Set `dot` for a leading square status dot. Always uppercase, wide-tracked — pass plain text.
